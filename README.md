# Журнал тренера

Мобильное веб-приложение для тренера функциональных тренировок: база клиентов, планы тренировок,
история занятий и заметки. Рассчитано на одного пользователя — самого тренера — и в первую очередь
на работу со смартфона.

## Возможности

- **Клиенты** — добавление, редактирование, поиск по имени, телефону и цели. В профиле: цель,
  ограничения по здоровью (подсвечиваются при составлении тренировки), заметки и статистика.
- **План тренировок** — тренировки со статусом «В плане». Их можно корректировать в любой момент.
- **Конструктор тренировки** — упражнения из базы или новые; для каждого: подходы с повторениями,
  весом, временем и/или дистанцией, отдых, комментарий по технике, порядок упражнений.
  При добавлении упражнения подставляются значения с прошлой тренировки клиента.
- **Проведение** — во время занятия подходы отмечаются касанием, затем тренировка переводится
  в историю кнопкой «Провести».
- **История** — все проведённые тренировки клиента в профиле; любую можно открыть, посмотреть,
  отредактировать или повторить как новый план.
- **Заметки** — к тренировке (автосохранение прямо на экране просмотра) и к каждому упражнению.
- **Прогресс** — лучшие веса и последние результаты клиента по каждому упражнению.
- **База упражнений** — более 40 упражнений «из коробки», можно добавлять свои.
- **Резервная копия** — экспорт и импорт всех данных в JSON-файл.
- **Синхронизация** — опциональный аккаунт через Supabase (magic link); local-first: офлайн в IndexedDB, облако при наличии сети.

## Хранение данных

Если настроен Supabase (есть `.env`), **единственный источник правды — облако**. IndexedDB на устройстве —
только кэш для офлайна: при входе он полностью подменяется данными из Supabase (пустая таблица в облаке =
пустой список клиентов в приложении). Без `.env` приложение работает только локально через Dexie/IndexedDB.

### Настройка Supabase

1. Создайте Free-проект на supabase.com.
2. В SQL Editor выполните [`supabase/migrations/20261101120000_init.sql`](supabase/migrations/20261101120000_init.sql).
3. Скопируйте `.env.example` → `.env`, вставьте Project URL и anon key.
4. Auth → URL Configuration: добавьте `http://localhost:4317/account` и URL прод-сайта в Redirect URLs.
5. Перезапустите `yarn dev`. Войдите по email и паролю на экране входа.

## Стек

Vite, React 19, TypeScript, CSS Modules, Base UI, React Router, Dexie, Supabase.

## Запуск локально

```bash
yarn
yarn start
```

Приложение откроется на http://localhost:4317. Сервер слушает все интерфейсы, поэтому с телефона
в той же Wi-Fi сети можно открыть `http://<IP-компьютера>:4317`.

Сборка продакшен-версии:

```bash
yarn build
yarn preview
```

Проверки:

```bash
yarn typecheck
yarn lint
yarn test
yarn test:e2e
```

Перед коммитом автоматически запускаются `yarn lint`, `yarn typecheck` и `yarn test`.

## CI/CD

Пайплайн — GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)), запускается на каждый
push в `main` и на pull request:

1. **quality** — `yarn lint`, `yarn typecheck`, `yarn test`, `yarn build`.
2. **e2e** — Playwright (Chromium, `yarn test:e2e`); отчёт и трейсы выгружаются артефактом `playwright-artifacts`.
3. **deploy** — только для `main` и только после успешных quality и e2e: выкладка в Vercel (production).

Для деплоя добавьте в Settings → Secrets and variables → Actions секреты `VERCEL_TOKEN`,
`VERCEL_ORG_ID` и `VERCEL_PROJECT_ID` (значения ID — в `.vercel/project.json`). Без них шаг деплоя
пропускается. Если в Vercel включена автодеплой-интеграция с Git, отключите её, чтобы не было двойного деплоя.

## Установка на телефон (офлайн)

Приложение — PWA: после установки на экран «Домой» интерфейс кэшируется service worker’ом,
а данные клиентов и тренировок уже лежат в IndexedDB на устройстве.

1. Разместите сборку (`yarn build`) на **HTTPS** (локальный `http://192.168…` для офлайна
   на iPhone не подходит — Safari требует защищённый контекст для service worker).
2. Один раз откройте сайт онлайн в Safari / Chrome, чтобы скачался кэш.
3. Safari → «Поделиться» → «На экран „Домой“» (или «Установить приложение» в Chrome).
4. Запускайте с иконки «Тренер» — дальше можно без интернета.

Аккаунт, синхронизация и резервная копия — иконка профиля на экране «Клиенты».
